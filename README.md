# V. Vishwanath ♥ Heamavathi — Free Wedding Invitation

## Included
- Traditional South Indian temple-inspired gold/red design
- Opening bell screen
- English/Telugu language toggle
- Countdown to 05 September 2026, 4:00 AM IST
- Haldi & Mehendi event
- Wedding venue + Google Maps button
- Family blessings
- Photo gallery placeholders
- Share Invitation button
- Optional background music

## Add your own photos
Replace the six `YOUR PHOTO` blocks in `index.html` with `<img>` elements, or ask ChatGPT to do it after you upload the photos.

## Add music
Put your own legally usable MP3 at:
`assets/music.mp3`
Then uncomment the `<source>` line in `index.html`.

## Free hosting
The easiest option is GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, e.g. `wedding-invitation`.
3. Upload `index.html` and the `assets` folder.
4. In repository Settings → Pages, choose the `main` branch and root folder.
5. GitHub will provide a free `github.io` invitation URL.
